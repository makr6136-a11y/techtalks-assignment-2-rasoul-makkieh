## 1. Chosen Niche

**Long-term target role:** Full-Stack Developer, remote
**Near-term entry point:** junior or intern Full-Stack / web developer, local (Lebanon)

This two-stage framing is a result of the research, not the starting assumption. The remote listings I analyzed had no genuine entry point — 5+ years, four years behind a "Junior" title, and Lead level — while the only role in the sample I could apply to today is local. The sequencing is set out in [`roadmap.md`](roadmap.md).

### Why Full-Stack

In university I took Database Design, where I learned SQL. I studied how data is stored, its data types, primary keys, foreign keys, and constraints, and how to create tables and join them together.

I also took Object Oriented Programming in Java. There I learned how to create classes, work with files, and use nested classes, abstract classes, interfaces, and data structures. Together with Database Design, this is backend work.

On the frontend side, I took a Web Design course covering HTML and CSS, and I built a website using HTML and CSS only. Programming I and II in C++ gave me the fundamentals: logic, control flow, and data structures.

Next semester I will take Web Programming I, Database Programming, Object Oriented Programming II, and Software Design. These cover both frontend and backend. At the same time I am learning Next.js in the bootcamp, which is also full-stack. My university courses and my bootcamp are moving in the same direction, so Full-Stack is the niche that uses everything I am building.

### Why not the alternatives

- **Frontend only:** I would work only with HTML and CSS and ignore the backend skills I already have from SQL and Java.
- **Backend only:** I would ignore the HTML and CSS work I have done and the Next.js I am learning now.
- **DevOps:** I have no background in CI/CD or Docker, so I would be starting from zero instead of building on what I already know.

*Market evidence supporting this choice is documented in [`market-research.md`](market-research.md).*
